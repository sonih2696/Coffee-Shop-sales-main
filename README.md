# ☕ Coffee Shop Sales Dashboard

## 📌 Overview

This project presents an interactive **Coffee Shop Sales Dashboard** built to analyze sales performance, customer footfall, product demand, store performance, and ordering patterns.

The analysis uses transaction-level coffee shop sales data and converts it into business-focused visual insights through an interactive dashboard.

## 🎯 Project Objectives

- Analyze overall coffee shop sales performance
- Track total sales and customer footfall
- Understand sales and order patterns by time and day
- Compare performance across store locations
- Identify top-performing products
- Analyze product category and order-size distributions
- Identify trends that can support business decision-making

## ▶️ How to Use

1. Open the Excel dashboard file.
2. Use the **Month Name** slicer to filter the dashboard by month.
3. Use the **Day Name** slicer to filter results by weekday.
4. Explore the charts to understand sales, footfall, product, and operational patterns.
5. Use the raw transaction data for further analysis if required.
